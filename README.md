# Kotlin Beginner Projects

This repository contains three beginner-friendly Kotlin console applications developed to practice programming fundamentals such as user input, variables, conditional statements, and calculations.

## Projects

### 1. BMI Calculator

Calculates a user's Body Mass Index (BMI) using their weight and height.

#### Features
- Accepts weight in kilograms (kg)
- Accepts height in meters (m)
- Calculates BMI
- Displays BMI category:
  - Underweight
  - Normal weight
  - Overweight
  - Obese

#### Formula

BMI = Weight (kg) / Height² (m²)

---

### 2. Grade Checker

Determines a student's grade based on marks entered by the user.

#### Grading Scale

| Marks | Grade |
|---------|---------|
| 80 - 100 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | E |

---

### 3. Temperature Converter

Converts temperature from Celsius to Fahrenheit.

#### Formula

Fahrenheit = (Celsius × 9/5) + 32

#### Features
- Accepts temperature in Celsius
- Converts to Fahrenheit
- Displays the converted value
